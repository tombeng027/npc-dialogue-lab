Reference / Quest authoring

Make quests completable

Connect NPC quest lines to real locations, actions, inventory items, and rewards.

The quest generator uses the NPC's quest line and guidance together with your world action catalog. It will only create requirements that correspond to configured actions and items.

1. Add a quest line

In NPC Studio, give each quest a unique, stable ID. Use that same ID in guidance and rewards.

fix_the_furnace, retrieve_mithril_ore

2. Describe intent

Quest requirements guidance uses one quest_id: instruction per line. Name the intended items, their order, and the final action.

fix_the_furnace: Collect heatproof stones, recover Grom's hammer, then use both to repair the furnace.

Guidance steers generation; the world map remains authoritative. Every named item and action must exist in World & Inventory.

3. Build the world path

For each needed resource, create a Gather an item action with a stable item ID. Create a Use items / perform task action for the final objective and configure exactly what it consumes.

Deepstone Mine / gather_heatproof_stones -> heatproof_stone x3 Old Watchtower / recover_grom_hammer -> grom_hammer x1 Ironforge Smithy / repair_furnace -> consumes heatproof_stone x3, grom_hammer x1

Action IDs are assigned when created and kept when actions are edited. Item IDs in rewards and consumes must match exactly.

4. Set coin payouts

NPC quest coin rewards use one quest_id: amount per line and pay once after all generated steps are completed.

fix_the_furnace: 50 retrieve_mithril_ore: 30

For item sales, create a Sell items for coins action, specify the consumed item quantities, and set coins earned per use.

Common blockers

  • Quest ID not available: add it to that NPC's Quest lines.
  • No world action completes the quest: create the final Use action and make guidance name it.
  • Required item cannot be gathered: add a Gather action whose reward item ID exactly matches the Use action's consumed ID.
  • Action is impossible in order: make sure each required Gather action comes before the Use action, and configure sufficient quantities.
  • Reward does not pay: confirm the quest reward uses the exact quest ID and a non-negative coin amount.
When a conversation cannot generate a valid quest from the current world, the Troubleshooting panel names the missing action or item and suggests what to add.
