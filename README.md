# npc-dialogue-lab
An NPC generator module that allows you to create custom NPCs by defining specific metrics, converse with them dynamically, and generate contextual quests based on active world events.

NPC Dialogue Lab is a module for creating and interacting with dynamic Non-Player Characters (NPCs).

Custom Generation: Define specific NPC traits, stats, and behavior metrics.

Interactive Dialogue: Engage in real-time conversations with generated NPCs.

Context-Aware Quests: Automatically generate relevant quests based on active player actions and world state updates.
